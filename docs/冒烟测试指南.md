# 冒烟测试指南

## 一、什么是冒烟测试

冒烟测试（Smoke Testing）是在软件构建后进行的快速验证测试，用于确认系统的基本功能是否正常工作。如果冒烟测试失败，则不需要进行更深入的测试。

## 二、测试文件

| 文件 | 说明 |
|-----|------|
| [冒烟测试检查清单.md](./冒烟测试检查清单.md) | 手动测试检查清单 |
| [smoke-test.bat](../scripts/smoke-test.bat) | Windows自动化测试脚本 |
| [smoke-test.sh](../scripts/smoke-test.sh) | Linux/Mac自动化测试脚本 |

## 三、快速执行

### 自动化测试（推荐）

**Windows:**
```bash
cd d:\Project\java\cool-community\scripts
smoke-test.bat
```

**Linux/Mac:**
```bash
cd scripts
chmod +x smoke-test.sh
./smoke-test.sh
```

### 手动测试

按照 [冒烟测试检查清单.md](./冒烟测试检查清单.md) 逐项执行测试。

## 四、测试前准备

### 1. 启动依赖服务

```bash
# 启动 MySQL
net start mysql

# 启动 Redis
redis-server

# 启动 Elasticsearch (可选)
elasticsearch

# 启动 RabbitMQ (可选)
rabbitmq-server
```

### 2. 启动应用服务

```bash
# 启动后端
cd community-server
mvn spring-boot:run

# 启动前端
cd frontend
npm run dev
```

### 3. 验证服务状态

```bash
# 检查后端服务
curl http://localhost:8082/api/post/list?page=1&pageSize=1

# 检查前端服务
curl http://localhost:5173
```

## 六、测试结果判定

| 状态 | 条件 | 后续操作 |
|-----|------|---------|
| ✅ 通过 | P0全部通过，P1通过率≥90% | 进入详细测试 |
| ⚠️ 有风险 | P0全部通过，P1通过率<90% | 修复后重新测试 |
| ❌ 不通过 | P0存在失败 | 阻断发布，立即修复 |

## 七、常见问题排查

### 1. 服务启动失败

```bash
# 检查端口占用
netstat -ano | findstr :8082
netstat -ano | findstr :3306
netstat -ano | findstr :6379

# 检查进程
tasklist | findstr java
```

### 2. 数据库连接失败

```bash
# 检查MySQL服务
net start mysql

# 检查连接
mysql -u root -p -e "SELECT 1"
```

### 3. Redis连接失败

```bash
# 检查Redis服务
redis-cli ping
```

### 4. 接口返回500错误

- 检查后端日志
- 检查数据库连接
- 检查Redis连接

## 九、持续集成

可以将冒烟测试集成到CI/CD流程中：

```yaml
# .gitlab-ci.yml 示例
smoke-test:
  stage: test
  script:
    - ./scripts/smoke-test.sh
  only:
    - main
    - develop
```

```yaml
# Jenkinsfile 示例
stage('Smoke Test') {
    steps {
        sh './scripts/smoke-test.sh'
    }
}
```
